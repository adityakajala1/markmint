# ExamScope

ExamScope is an intelligence engine that analyzes academic patterns. It automatically digests PyQs (Previous Year Questions), syllabus documents, and study materials, mapping them into a unified knowledge graph.

By running chronological analysis (Exam DNA) and backtesting against historical data, ExamScope identifies structural trends, predicts upcoming topic focus, and explicitly justifies every claim using verifiable evidence traces.

## Core Features
- **Isolated Evidence Graphs**: Study material strictly provides context; it never contaminates historical exam frequencies.
- **Exam DNA**: Detects repetition behaviors, unit weighting, and format priorities.
- **Evolution Engine**: Identifies shifts in difficulty and exam format (e.g. tracking when a course becomes heavily implementation-focused).
- **Temporal Backtesting**: Proves predictive validity by sliding a historical window backwards in time, physically blocking future data leaks.
- **Semantic Discovery**: A hybrid NLP intent engine targeting questions, families, study material, and structural trends.
